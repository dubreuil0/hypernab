Appearance

Language

The language of the app. “Same as Windows” follows Windows when the app has that language, otherwise English. The default subtitle language set to “Interface language” follows this too.

Layout

Compact: plain rows and little space. Normal: wide cards. Running downloads are not affected.

Theme

Dark, light, or follows Windows. Applied immediately.

Accent color

The color used on buttons, progress and selections.

Text size

Independent of the layout. Your choice is saved and applied at once.

Download

Download folder

New downloads are saved here. Ongoing and half-finished downloads finish in their own folder.

Smart file name

New downloads use a clean name, the known release year and the verified picture height. Old files are not changed.

Sort files into folders by type

Off: everything goes into the one download folder. On: new downloads go into Video, Music, Images, Documents, Archives, Programs and Other folders inside it. Files already downloaded are never moved.

Folder layout

New downloads only. The series folder is used for episodes added in bulk; with no information no extra folder is made.

Default quality

The highest picture preselected in the quality list. You can always pick a lower one from the list.

Prefer a compatible format

If the same quality exists as H.264 / MP4, choose it. AV1 and VP9 do not play on some older devices and programs.

Subtitles

Off by default: a video is saved as it is. When turned on, the subtitle of the video on the page is found automatically. Embed: inside the video file (opens in the player). Side file: a .srt next to the video. The video is not re-encoded.

Deep verification on every download

When done, decodes the video from start to end looking for errors. Safe but slow; needs FFmpeg.

Confirmation windows

Show again the cancel and clear confirmations you answered with “Don’t ask again”.

Speed and connections

Speed limit per download

0 = unlimited. Applies to downloads that start or resume from now on.

MB/s
Connections per download

The fast path splits a file into this many pieces. A very high value can slow some sites down; 8 is recommended.

Automatic retry

On a temporary network problem, the download is retried this many times without asking you.

Queue and schedule

“Add for later” target

Downloads added for later wait in this queue.

Scheduler

Starts the selected queue at the time you set. The app and the computer must be on.

When downloads finish

Applies when all current downloads finish successfully; there is a 60-second window to cancel first. It is cancelled on an error or a pause.

Desktop

Start with Windows

Hypernab is ready when the computer starts.

Start in the tray

When starting with Windows the window does not open; the icon waits in the tray.

Minimize to the tray on close

Closing the window does not stop downloads. When off, closing the window safely exits the app.

Offer links from the clipboard

When the window gets focus and the clipboard holds a link, a quiet strip offers to add it. The clipboard is only read while this is on; nothing is stored or sent.

Notifications

Show a Windows notification when a download finishes or fails.

Browser connection

Rebuilds the connection record if the extension cannot find the app.
